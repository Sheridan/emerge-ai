# DECISIONS

Журнал решений автономной сессии разработки emerge-ai. Формат: дата — решение — контекст.

## 2026-11-23

- **Режим автономки**: работа по `openspec/changes/emerge-ai-foundation/tasks.md` группами 1→14; коммит после каждой зелёной группы (согласовано с пользователем); `[x]` в tasks.md только после фактического прохождения проверки задачи.
- **Вопросы без блокировки**: `question`-инструмент запрещён на время отсутствия пользователя; всё требующее решения человека — в `OPEN_QUESTIONS.md`, работа продолжается по безопасному дефолту.
- **Граница системы**: mutate разрешены только внутри репозитория проекта, `/tmp`, `/var/db/repos/emerge-ai-test`, `/etc/portage/repos.conf/emerge-ai*`. Запрещены себе: живой emerge (кроме `-p/--info/--version`), ebuild merge, etc-update, systemctl, снапшот-мутации. `sudo` доступен (NOPASSWD проверен) — использовать только для chown/подготовки тестовых путей оверлея.
- **Тестовый LLM**: только локальный strata `http://127.0.0.1:8080/v1` (модель qwen3.8-flash-next-unsloth-ud-q5_k_xl; tool-calling и reasoning проверены живыми запросами; контекст 204k).
- **Python-окружение**: системный Python 3.14.7 + портage importable из системы; venv `.venv` создаётся с `--system-site-packages`, чтобы видеть `portage` и системный `pytest`; runtime-зависимости проекта — только stdlib (http-клиент на urllib).
- **Версия проекта**: `3.0.82` (мажор.минор.билд портage); совместимость по major.minor, runtime-проверка, при несовпадении — сообщение и ненулевой выход.
- **Раскладка пакетов**: `src/emerge_ai/`, тесты `tests/`, pytest `pythonpath=["src"]`.
