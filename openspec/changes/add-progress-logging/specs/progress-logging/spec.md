# Spec Delta

## Purpose

Определяет, как emerge-ai делает видимой текущую деятельность приложения: какие строки
активности печатаются по умолчанию, что добавляет `-v`/`--verbose`, и как эти строки
совместимы с потоками emerge, console-output и требованиями к секретам.

## ADDED Requirements

### Requirement: Анонс значимых действий по умолчанию

Перед каждым значимым действием emerge-ai SHALL писать в stderr одну строку с префиксом
`emerge-ai: `, описывающую, что происходит: запуск внешней команды с полным argv; обращение
к LLM (модель, число сообщений, наличие tools); tool-call agent-петли с аргументами;
web-запрос с URL. Строки активности SHALL не трогать stdout и коды выхода.

#### Scenario: Живой прогон виден

- **WHEN** выполнено `emerge-ai -a app-editors/vim` без `-v` с настроенным endpoint
- **THEN** в stderr видны строки о запуске emerge с argv и об отправке запроса к LLM до того, как появился его результат

#### Scenario: Tool-call виден

- **WHEN** в разборе агента модель вызывает `pretend_emerge` или `grep_log`
- **THEN** до исполнения инструмента в stderr напечатана строка с его именем и аргументами

#### Scenario: stdout не затронут

- **WHEN** обычный merge-прогон с активностью выводит stdout в файл
- **THEN** в файле только вывод emerge без изменений, все строки активности — в stderr

#### Scenario: Тихие режимы не молчат

- **WHEN** прогон выполнен в режиме `--pretend` или `--noninteractive`
- **THEN** строки активности печатаются в stderr как обычно

### Requirement: Детальные логи при -v

При `-v`/`--verbose` (включая кластеры коротких опций) emerge-ai SHALL дополнительно печатать
в stderr тело каждого запроса к эндпоинту (JSON с капом фиксированного размера и плашкой
усечения) и длительность вызова. Флаг SHALL передаваться emerge без изменений. Без `-v` тело
запроса SHALL не печататься вовсе.

#### Scenario: Запрос показан

- **WHEN** выполнено `emerge-ai -av ...` с настроенным endpoint
- **THEN** перед результатом каждого LLM-вызова в stderr напечатан JSON запроса (при переполнении — усечённый с плашкой), без ошибок и предупреждений

#### Scenario: Без -v тел нет

- **WHEN** выполнено `emerge-ai -a ...` без `-v`
- **THEN** в stderr есть только короткие строки анонсов, JSON запросов отсутствует

### Requirement: Дисциплина секретов и шума

Строки активности и verbose-дампы SHALL не содержать API-ключ, заголовок `Authorization`
и иные материалы аутентификации; значения, пересекающиеся с ключом, SHALL маскироваться.
Тривиальные read-only пробы окружения (`findmnt`, чтение `/proc`) SHALL не порождать строк
активности. Оформление строк активности SHALL следовать console-output: информационный стиль
без цветового акцента, в pipe — полностью plain.

#### Scenario: Ключ не утекает

- **WHEN** выполнено `-v` с `api_key` в конфиге
- **THEN** ни в одном дампе stderr нет значения ключа и заголовка Authorization

#### Scenario: Пробы окружения молчат

- **WHEN** сбор машинного контекста выполняет `findmnt` и чтение `/proc/1/comm`
- **THEN** строк активности про эти команды нет

#### Scenario: Pipe без escape-кодов

- **WHEN** stderr прогона перенаправлен в файл
- **THEN** строки активности не содержат ANSI escape-кодов
