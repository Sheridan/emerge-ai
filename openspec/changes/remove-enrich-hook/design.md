# Design

## Context

Замысел (`hooks.py:1-5`): рантайм-реестр хуков, «вызываемых в ключевых точках» —
зарегистрированный через `set_hook` callback должен срабатывать перед enrich.
Фактическое состояние: `set_hook` вызывается только из теста; в `_run_pool`
(`cli.py:349-360`) перед `run_incident` стоит `run_hook(notify.get("pkg"), "pre-enrich", ...)`,
который без регистрации ничего не делает, а уведомления инцидентов уходят напрямую
из отчёта. Точка расширения никогда не была точкой расширения (M7).

## Goals / Non-Goals

**Goals:** удаление недостижимого кода без потери покрытия полезного поведения
теста; честность модулей (`hooks.py` не существует, пока нет спецификации уведомлений
через хуки).

**Non-Goals:** проектирование «правильного» hook-механизма под будущие уведомления;
изменение поведения `--pretend` или `_run_pool`; замена удалённого вызова чем-либо.

## Decisions

**D1. Удалить модуль, а не доводить его до ума.** Спецификация hook-уведомлений не
написана (REVIEW_NOTES прямо указывает: сначала спека, потом механизм); «довести»
означало бы выдумывать контракт API втихую. YAGNI + гит возвращает код по истории.
Рассмотренная альтернатива — оставить `hooks.py` с docstring «не используется»:
мёртвый код с обманывающим докстрингом был источником дефекта; отвергнута.

**D2. Тест переписать, а не удалить.** В имени живёт три обещания, и два из них —
ценные контракты `--pretend`: дословный вывод stdout эмуляции (assert'ы на точные
строки) и ровно один запуск emerge. Удаление теста вместе с hook'ом потеряло бы их.
Переписанный тест сохраняет все assert'ы про вывод/число запусков, теряет `calls`
и `set_hook(...)`; имя переименовывается в `test_pretend_prints_verbatim_runs_once`.
Альтернатива — оставить тест с пустышкой-хуком: сохраняет зависимость от удаляемого
модуля; отвергнута.

## Risks

- [Кто-то импортирует `emerge_ai.hooks` извне] → API не документирован и не входит в
  публичный контракт (README/specs молчат); для changelog помечен как BREAKING.
- [При переписывании теста потеряется покрытие `--pretend`] → assert'ы на дословный
  вывод и `len(sandbox.calls) == 1` сохраняются дословно; pytest сравнивает результат
  с эталоном до/после.
