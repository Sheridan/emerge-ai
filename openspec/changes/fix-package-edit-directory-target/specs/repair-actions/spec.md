# Spec Delta

## ADDED Requirements

### Requirement: Каталог вместо файла в канале правки package.*

Канал правки `package.*` SHALL выбирать цель по фактической файловой системе
`/etc/portage`: если `package.<kind>` — каталог, строка с аудит-маркером
пишется в `package.<kind>/<category>`, где `<category>` — категория атома из
строки; если это файл или отсутствует — append в `package.<kind>`, как сейчас.
Раскладка хоста SHALL NOT переписываться, правки вне `/etc/portage`
невозможны, а путь, названный оператору до исполнения, SHALL совпадать с
фактически записанным.

#### Scenario: Каталог с файлами по категориям

- **WHEN** `/etc/portage/package.accept_keywords` — каталог и выбранный вариант добавляет `=dev-libs/jemalloc-5.4.0-r2 ~amd64`
- **THEN** строка с аудит-комментарием `# emerge-ai:` дописана в `package.accept_keywords/dev-libs` (файл создан, если его не было), файл `package.accept_keywords` не создан, прочие файлы каталога не изменены, прогон продолжился с перезапуском emerge

#### Scenario: Файл остаётся файлом

- **WHEN** `package.use` — обычный файл и выбрана правка `use`
- **THEN** строка дописана в `package.use`, каталог не создан

#### Scenario: Цели нет — создаётся файл

- **WHEN** `package.accept_keywords` отсутствует в `/etc/portage`
- **THEN** создан обычный файл `package.accept_keywords` с этой строкой (каталожная раскладка не навязывается)

#### Scenario: Строка без категории

- **WHEN** `package.mask` — каталог, а строка правки не содержит атома с категорией (`*/* cuda`, set-атом, мусор от парсера)
- **THEN** строка дописана в зарезервированный файл `package.mask/emerge-ai` того же каталога (append, существующие строки целы), ничего не записано в имя, которое не является файлом внутри `/etc/portage`

#### Scenario: Цель недоступна как файл — отказа нет в тишине

- **WHEN** цель внутри каталога существует, но не является обычным файлом (например, подкаталог с именем категории) или запись невозможна
- **THEN** ни один файл не изменён, оператору напечатано сообщение с указанием цели и причины, прогон не завершается traceback'ом

#### Scenario: Показанный путь = записанный

- **WHEN** consent-формулировка варианта правки `package.*` показывает оператору строку «edit: …» и способ отмены
- **THEN** в них назван тот же путь, что и файл, в который реально записана строка (например, `package.accept_keywords/dev-libs`), и та же строка в анонсе активности

### Requirement: Отмена и обзор правок обходят каталоги package.*

Отмена правок прогона и обзор строк `package.*` SHALL обходить эти цели
рекурсивно, включая файлы внутри каталогов: изменены могут быть только строки с
аудит-маркером `# emerge-ai:` этого прогона, повторная отмена ничего не меняет,
опустевшие файлы и каталоги не удаляются.

#### Scenario: Отмена строки в файле категории

- **WHEN** прогон дописал строку в `package.accept_keywords/dev-libs` и его правки отменены
- **THEN** из этого файла удалены только строки этого прогона, строки пользователя целы, файл остался на диске (пустой, если своих строк не было), повторная отмена не изменила ни один файл

#### Scenario: Обзор каталога

- **WHEN** `package.use` — каталог с файлами категорий и запрашивается обзор строк правок
- **THEN** показаны строки из всех файлов каталога с различием «строка emerge-ai» / «строка пользователя»
