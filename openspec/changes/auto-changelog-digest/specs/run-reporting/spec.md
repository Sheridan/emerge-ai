# Spec Delta

## Purpose

Закрывает разрыв спека/кода в changelog-дайджесте: штатный путь — автоматический вызов после успешного прогона под опцией конфига, а не только ручная команда; фиксирует сохранение дайджеста в отчёт прогона и деградацию без LLM.

## MODIFIED Requirements

### Requirement: Changelog-дайджест собранных пакетов

При включённой опции emerge-ai SHALL для собранных пакетов извлекать changelog из локальных источников (news, GLESA, диффы USE) и внешних: release-changelog GitHub/аналогов, коммиты и merge-записи git-репозитория проекта; LLM SHALL отбирать самое важное и заметное. Дайджест SHALL печататься plain text и сохраняться в отчёт соответствующего прогона; ручной вызов `--changelog` SHALL оставаться работоспособным.

#### Scenario: Changelog с релизов
- **WHEN** у пакета есть GitHub-релизы и опция включена
- **THEN** changelog-дайджест содержит ключевые изменения между старой и новой версиями

#### Scenario: Источник недоступен
- **WHEN** у пакета нет доступного changelog-источника
- **THEN** в дайджесте указано отсутствие changelog, ошибка не генерируется

#### Scenario: Дайджест в отчёте прогона
- **WHEN** changelog-дайджест построен в ходе прогона
- **THEN** текст дайджеста сохранён в отчёте этого прогона наряду с прочими его данными

## ADDED Requirements

### Requirement: Автоматический changelog-дайджест после прогона

После успешного прогона, в котором были собранные пакеты, при включённой опции `changelog_digest` emerge-ai SHALL автоматически построить и напечатать changelog-дайджест этих пакетов и сохранить его в отчёт прогона; при ненастроенном LLM endpoint дайджест SHALL деградировать до сырого перечня собранных событий; при выключенной опции автоматический changelog-дайджест SHALL не выполняться и не создавать сетевых обращений.

#### Scenario: Автовызов после обновления
- **WHEN** опция `changelog_digest` включена и `emerge-ai -uDN @world` завершился успешно
- **THEN** после дайджеста прогона напечатан changelog-дайджест, отдельная команда не требовалась

#### Scenario: По умолчанию тихо
- **WHEN** опция `changelog_digest` не настроена и прогон завершился успешно
- **THEN** changelog-дайджест не строится, внешних обращений нет, вывод прогона не изменился

#### Scenario: Без endpoint — сырой перечень
- **WHEN** опция включена, LLM endpoint не настроен и прогон успешно собран
- **THEN** напечатан сырой перечень доступных changelog-событий без LLM-отбора, без ошибки

#### Scenario: Сбой дайджеста не портит прогон
- **WHEN** при построении changelog-дайджеста произошло необработанное исключение
- **THEN** код возврата прогона не изменился, в stderr напечатано предупреждение
