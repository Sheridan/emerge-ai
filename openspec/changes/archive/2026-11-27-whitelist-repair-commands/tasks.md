# Tasks

Зависимость: `plan-degraded-triage` (findings — источник вариантов).
С `consent-plan-dialogue` порядок любой: варианты уместны и в текущем гейте,
и в новом диалоге; «не исполняемо» из отчётов снимается по факту этого change.

## 1. Род «белая команда» в apply-канале

- [x] 1.1 `CommandSpec{name, argv_template, slots[], backup?, undo}` +
      исполнение через `gate.apply_variant` (единственная точка мутации):
      аудит до исполнения (argv, слоты, путь бэкапа), subprocess фиксированным
      argv (emaint/emerge — реальные бинарники, D1).
- [x] 1.2 Валидаторы слотов через `portage_compat`: членство атома в @world,
      формат CPV/keyword; двойной проход — до рендера варианта и повторно
      внутри apply (TOCTOU-отказ с сообщением, без исполнения).
- [x] 1.3 Действия: `emaint --check world` (read-only, инструмент песочницы
      агента); `emaint --fix world` (копия `world.emerge-ai.<run-id>.bak`
      перед модификацией, повторяемо); `emerge --deselect <атом>` (валидация
      членства; undo_text `emerge --noreplace <атом>` в аудите).
