# Spec Delta

## MODIFIED Requirements

### Requirement: Матрица автономности
По умолчанию каждое изменение системы требует подтверждения пользователя. С `--noninteractive` агент SHALL самостоятельно применять решения только для пакетов rest-tier; для tiers 1–4 и для откатов системы — записывать проблему в лог и завершаться с ненулевым кодом до начала мутаций. С `--i-understand-what-i-am-doing-and-take-full-responsibility-for-consequences` агент SHALL применять решения без подтверждений на всех tiers, включая откат, показывая выбранное решение и обоснование.

#### Scenario: Неинтерактив на критичном пакете
- **WHEN** при `--noninteractive` сбой затронул пакет tier 2
- **THEN** emerge-ai пишет проблему в лог и завершается с ненулевым кодом, ничего не меняя

#### Scenario: Флаг ответственности
- **WHEN** сбоевый пакет относится к tier 1 и передан флаг ответственности
- **THEN** агент применяет выбранное агентом решение без вопроса, с показом обоснования

#### Scenario: Ни одной мутации до вердикта
- **WHEN** неинтерактивный прогон получил отказ матрицы
- **THEN** команда merge не запускалась ни разу, в выводе — обоснование отказа

## ADDED Requirements

### Requirement: Проверка автономности перед мутациями
Перед каждым реальным (не демонстрационным) merge emerge-ai SHALL выполнять
проверку автономности по максимальному тиру затрагиваемых пакетов и режиму
запуска; ни одна мутация не должна начаться без вынесенного вердикта. Если тиры
вычислить не удалось, неинтерактивный запуск SHALL считать мутацию рискованной
и остановиться, интерактивный — продолжаться только с явного согласия
оператора.

#### Scenario: Rest-tier проходит
- **WHEN** неинтерактивный merge затрагивает только пакеты rest-tier
- **THEN** мутация выполняется, вердикт с обоснованием напечатан

#### Scenario: Неизвестные тиры в неинтерактиве
- **WHEN** неинтерактивный запуск не смог вычислить тиры плана
- **THEN** merge не начинается, причина остановки объяснена в выводе

#### Scenario: Интерактив не ухудшается
- **WHEN** интерактивный оператор уже ответил «y» на вопрос о продолжении
- **THEN** повторный вопрос не задаётся, merge выполняется как раньше

### Requirement: Аудит автоматных решений
Каждое автоматное (без участия человека) решение о мутации или об отказе в ней
emerge-ai SHALL записывать в журнал решений: режим, тиры, вердикт,
обоснование. В неинтерактивном режиме невозможность записать аудит SHALL
блокировать мутацию; в интерактивном — только предупреждать.

#### Scenario: AUTO-решение в аудите
- **WHEN** матрица разрешила неинтерактивный rest-tier merge
- **THEN** в журнале решений есть запись с вердиктом и обоснованием

#### Scenario: Журнал недоступен
- **WHEN** неинтерактив с разрешением rest-tier не может записать журнал решений
- **THEN** merge не выполняется, причина напечатана

### Requirement: Сообщения соответствуют проверкам
Сообщение CLI о прохождении проверки автономности SHALL печататься после
вынесения вердикта и содержать его фактический результат; текст, обещающий
проверку, которая не выполнялась, выводиться не должен.

#### Scenario: Честное сообщение при продолжении
- **WHEN** неинтерактивный прогон с флагом ответственности получил разрешение матрицы
- **THEN** в выводе напечатан вердикт с обоснованием, а не общее обещание будущей проверки
