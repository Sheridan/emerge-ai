# Proposal

## Why

После сбоя emerge-ai ограничивается советом: `_maybe_agent` (src/emerge_ai/cli.py:106-142)
вызывает только `IncidentAgent.propose` (src/emerge_ai/agent.py:384) и печатает текст
предложения с явной оговоркой «proposals only, nothing is executed»
(src/emerge_ai/cli.py:118). Все три ветки сбоя — plan-failed (cli.py:335-343), merge-сбой
в `-a` (cli.py:411-424) и merge-сбой обычного запуска (cli.py:313-324) — возвращают код
emerge, ничего не применяя. При этом consent gate с матрицей автономности и аудитом
уже реализован в `gate.gate()` (src/emerge_ai/gate.py:84-136), но production-кодом не
импортируется (REVIEW_NOTES H5). Решение пользователя: петлю доводить — предложение
агента должно доходить до проверяемого применения.

## What Changes

- После сбоя CLI собирает исполняемые варианты из proposal'а агента (только из
  ограниченного набора типизированных действий, не из произвольных команд), предъявляет
  их через `gate.gate()` и при явном согласии оператора применяет выбранный вариант.
- В неинтерактивном запуске согласие заменяется матрицей автономности
  (`gate.autonomy_decision`, src/emerge_ai/gate.py:48-71); отказ/deny = система не
  тронута, поведение как сейчас (advisory).
- После применения варианта исходный сбойный вызов emerge повторяется через штатный
  `runner.run_emerge_capturing` для проверки починки; успех/неуспех определяется его
  кодом выхода.
- Защита от рекурсии: не более 2 циклов «применение → повтор» на прогон; после
  исчерпания — отчёт и код выхода как сейчас.
- Переходы состояние-машины не расширяются: INCIDENT → MERGE уже разрешён
  (src/emerge_ai/state.py:28-29).
- Advisory-вывод предложения сохраняется во всех случаях, включая отказ.

### Modified Capabilities

- `agent-loop-consent`: добавляются требования про применение выбранного решения

  после применения с лимитом попыток.

## Impact

- Код: `src/emerge_ai/cli.py` (сборка вариантов и вызов гейта в трёх ветках сбоя),
  `src/emerge_ai/agent.py` (варианты как структура, не только текст), опора на
  `gate.py` без изменений его логики.
- Тесты: юниты на seam в `tests/test_cli.py` (подтверждение/отказ/deny), связочный
  e2e с stub emerge и fake-клиентом в духе `tests/test_replay_e2e.py`.
- Документация: README — раздел о поведении после сбоя убрать оговорку «ничего не
  применяется».
- Смежные изменения: `wire-autonomy-gate` (тот же гейт на общем mutate-пути),
  `wire-risk-flag` (флаг `--i-understand-the-risks` для матрицы), `wire-journal-writer`
  (писатель журнала живёт в этой петле и идёт после неё).
