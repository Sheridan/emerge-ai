# Tasks

## 1. Seam применения в CLI

- [x] 1.1 В cli.py ввести seam `_incident_flow(run, mode, plan, *, audit_path, etc_dir,
      gate_fn, input_fn, confirm_fn, interactive)`: построение списка `gate.Variant`,
      вызов `gate.gate`, разбор решения.
- [x] 1.2 Исполняемые варианты — детерминированный белый список `agent.typed_variants(incident)`
      (retry / env-retry / package-edit / overlay-copy), а не разбор ответа модели:
      текст модели остаётся чисто консультационным (защита от prompt-injection сильнее
      исходной формулировки «структурированная часть ответа агента»); `AgentResult` не менялся.
- [x] 1.3 Действия собирает `_apply_action` — единственный интерпретатор мутаций:
      `retry` (без мутаций), `env-retry` (env повтора), `package-edit` через `config_edit`
      (идемпотентен: «already present — skipped»), `overlay-copy` через `overlay`;
      неизвестный тип → `ValueError` (fail-closed).
- [x] 1.4 Обе ветки сбоя подключены: план-сбой (`while rc != 0` перед разбором плана) и
      merge-сбой в общем мутационном блоке (покрывает и `-a`, и обычный запуск).
      Петля включается только когда агент дал предложение (`proposal is not None`) —
      без agent-слоя поведение остаётся прежним консультационным.
- [x] 1.5 Счётчик циклов — `run.repair` + `REPAIR_LIMIT = 2`; при исчерпании лимита
      seam не запускается, печатается `repair limit (2 apply->retry cycles) reached`.
