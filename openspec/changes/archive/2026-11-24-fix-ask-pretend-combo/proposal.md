# Proposal

## Why

При комбинации `-a --pretend` фаза плана честно отрабатывает в pretend (`cli.py:328-333`), но после вопроса «Proceed?» строка `merge_args = drop_flags(emerge_args, ASK_FLAGS + PRETEND_FLAGS)` (`cli.py:375`) снимает **оба** флага и запускает РЕАЛЬНЫЙ merge (`cli.py:410`). Нативный emerge при `-a -p` merge не запускает никогда, а вопрос «Proceed?» в этой ветке вообще не задаётся (`cli.py:371` выполняется и для pretend). Оператор, явно попросивший «только показать», получает внезапную установку системы — риск H1.

## What Changes

- Pretend побеждает: при наличии `--pretend`/`-p` (в том числе в кластере вида `-ap`) emerge-ai ограничивается фазой плана — штатный pretend-вывод + обогащение, вопрос «Proceed?» НЕ задаётся, merge НЕ запускается никогда, даже когда передан и `-a`.
- Код выхода `-a -p` — код выхода pretend-резолва (сейчас для `-p` это уже так: `cli.py:333-343,427-428`; для ветки `ask` это изменится).
- `-a` без `-p` ведёт себя как раньше: план-фаза, «Proceed?», merge после подтверждения.
- Правка точечная в обработчике `-a` в `cli.py`: ветка merge (`cli.py:361-425`) выполняется только когда pretend не запрошен.

**BREAKING** для поведения CLI: скрипты, которые использовали `emerge-ai -a -p` как «показать и спросить», после этого изменения не получат ни вопроса, ни merge; для вопроса нужен `-a` без `-p`. Спек `run-reporting` («Enrich для pretend/ask») формально допускал вопрос при `-a -p` — дельта сужает его явным условием.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `cli-compat`: новое требование о разрешении комбинации `--ask`/`--pretend` (pretend доминирует, merge недостижим). Базовый спек cli-compat описывает passthrough и собственные флаги, но перехват/комбинации `emerge`-флагов `-a`/`-p` не нормированы нигде; `run-reporting` («Enrich для pretend/ask») не трогаем — он о сценарии `-a` без pretend, он не меняется.

## Impact

- `src/emerge_ai/cli.py` — обработчик `ask`-ветки (`361-425`) и условие входа в merge.
- `tests/test_cli.py`, `tests/test_cli_integration.py` — тесты связки `-a -p` (без вопроса, без merge, rc резолва); частичное покрытие кластеров уже есть, комбо — нет (замечание L3, тестовый слой добирает смежное `cover-config-edit-and-ask-pretend`).
- `README.md` — таблица флагов/разбор `-a`, уточнение семантики комбинации.
- Зависимости: `cover-config-edit-and-ask-pretend` пишет CLI-тесты связки строго после принятия этой семантики.
