# Spec Delta

## ADDED Requirements

### Requirement: Вопрос оператору маркированной строкой
Системный промпт агента SHALL требовать, чтобы вопросы оператору формулировались отдельными строками с префиксом `QUESTION: ` в финальном тексте. Маркер — единственный канал вопроса: emerge-ai SHALL NOT создавать интерактивного ожидания ответа внутри цикла агента; выведенный текст с маркерами остаётся финальным предложением, а подсветка маркеров относится к выводу.

#### Scenario: Модели не хватает данных
- **WHEN** агенту для вывода причин не хватает факта, который может знать только оператор
- **THEN** финальный текст содержит строку с префиксом `QUESTION:`, цикл агента завершился штатно, ввода агент не ждёт

#### Scenario: Неинтерактивный режим
- **WHEN** сбой разобран с `--noninteractive` и текст содержит `QUESTION:`
- **THEN** текст выведен как есть, режим не прерывается и не ждёт ответа
