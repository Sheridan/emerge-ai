# Spec Delta

## ADDED Requirements

### Requirement: Настройка цвета LLM-вывода
Конфигурационный файл SHALL поддерживать опцию `llm_colors` — палитру блоков пользовательского вывода LLM: отдельно цвет основного текста, рассуждений и строк-вопросов (`QUESTION:`). Допустимы имена базовых цветов терминала и отключение цвета элемента; значения, задающие произвольные escape-последовательности, не допускаются. Нераспознанное значение SHALL откатываться к дефолту с предупреждением, работа продолжается.

#### Scenario: Валидная палитра
- **WHEN** в конфиге `llm_colors` задан корректными именами цветов
- **THEN** блоки LLM-вывода окрашены этими цветами в TTY

#### Scenario: Невалидное имя цвета
- **WHEN** в `llm_colors` указано нераспознанное имя цвета
- **THEN** emerge-ai предупредил о значении, использовал дефолт и продолжил работу

#### Scenario: Палитра не включает цвет в pipe
- **WHEN** `llm_colors` задан, но вывод идёт в pipe
- **THEN** вывод LLM-блоков plain, предупреждений нет
