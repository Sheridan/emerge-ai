# Proposal

## Why

В корень репозитория коммитом d886e4a попал `manifest` (116 байт) — stdout
живого теста оверлея («manifest for /tmp/pytest-of-sheridan/… done»): тест того
времени писал вывод в рабочую директорию (корень репозитория при запуске
pytest), а `git add` подхватил артефакт (REVIEW_NOTES L7). Файл не нужен ни
коду, ни тестам, но остаётся в каждом checkout и намекает на ложный артефакт
продукта. Наблюдаемое поведение продукта не меняется, поэтому изменение идёт
без спеков (skip_specs).

## What Changes

- Файл `manifest` удаляется из git (`git rm manifest`) — вместе с индексом и
  рабочей копией; содержимое — мусор вывода теста, восстанавливать нечего.
- В `.gitignore` добавляется строгий корневой шаблон `/manifest`, чтобы
  повторная случайная генерация (старые запуски, ручные проверки) не могла
  снова попасть в коммит; шаблон не задевает легитимные `Manifest` оверлеев
  (регистр значим, путь заякорен в корне).

## Impact

- Репозиторий: удаление одного файла из индекса, одна строка в `.gitignore`.
- Код/тесты/документация: не затрагиваются — ни один модуль `manifest` не
  читает (проверено grep: совпадения только про `Manifest` оверлея в
  overlay.py и тексты тестов).
- Пользователи: замечают только чистый `git status` после pull; история
  коммита d886e4a не переписывается.
- Риски смежностей: нет — изменение не пересекается с остальными шестью
  изменениями секции.
