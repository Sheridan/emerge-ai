# Design

## Context

- `runner.confirm(prompt="Proceed? [y/N] ", stream=sys.stdin)` (`runner.py:53`); тело — `input(prompt)` с `except EOFError → False` (`runner.py:54-59`), `stream` не читается.
- Вызовы только в cli: `cli.py:371` (ветка `--ask`) и `cli.py:401` (post-incident подтверждение), оба — с одним аргументом prompt.
- Тесты согласия патчат `builtins.input` (устоявшийся паттерн, см. `tests/test_agent.py`); ни один тест не передаёт `stream`.
- REVIEW_NOTES L2 (`REVIEW_NOTES.md:191-194`) формулирует вилку: «убрать параметр или читать из stream».

## Goals / Non-Goals

**Goals:**
- Сигнатура `confirm` обещает ровно то, что делает.
- Ноль поведенческих изменений, ноль правок тестов.

**Non-Goals:**
- Редизайн seam-ов ввода в runner; изменение текста промпта и семантики EOF.

## Decisions

### D1: убрать параметр, а не начать читать stream
`stream` — мёртвый API: нет ни одного передающего call-site, нет ни одного теста, нет спековой ссылки. Чтение из stream (`stream.readline()`) потребовало бы и печати промпта в этот поток (голый `readline` не выводит prompt, в отличие от `input()`), то есть осознанной смены канала вывода — несоразмерно гигиенической правке уровня L. Тестовый seam уже есть и работает: патч `builtins.input`. Альтернатива «оставить и задепрейтить» — для параметра, который никто не передаёт, только шумит.

### D2: docstring документирует фактический seam
В docstring фиксируется: читается `sys.stdin` через `input()`, в тестах подменяется `builtins.input` — чтобы следующая правка не «доделывала» stream молча.

## Risks / Trade-offs

- Внешние (вне репозитория) потребители `runner.confirm` с именованным `stream` получили бы TypeError — приёмлемо: runner не публичный API пакета (внутренний модуль, в README/docs не экспортируется), а валидаторов совместимости у CLI-обёрток нет.
- Прочее: `sys` в `runner.py` остаётся нужен (`run_emerge_capturing` пишет в `sys.stdout`) — импорт не трогаем.

## Migration Plan

Симметричная правка в одном файле; коммит не трогает ни одного call-site. Откат — реверт одного коммита.
