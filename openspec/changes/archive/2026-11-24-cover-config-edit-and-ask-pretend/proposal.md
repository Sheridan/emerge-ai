# Proposal

## Why

`config_edit.py` — канал записи в `/etc/portage/{package.use,package.accept_keywords,mask,...}` с аудит-комментариями — не имеет собственного тестового модуля: два поверхностных smoke-теста живут в `tests/test_ladder.py:30-49`, формат аудита, парсинг `get_package_edit_lines` и область записи не закреплены ничем (замечание L3, REVIEW_NOTES.md:196-200). Комбинация `-a -p` также не покрыта: все CLI-тесты с `-a` (`test_cli.py:53-124`, `test_cli_integration.py:36-164`) прогоняют её без `--pretend`, то есть есть/merge-семантику, а не «pretend побеждает». Наблюдаемое поведение изменение не вводит (только тесты), поэтому дельт спецификаций нет (`skip_specs`); семантика `-a -p` закрепляется по финальному спеку `cli-compat` «Доминирование --pretend над --ask» из `fix-ask-pretend-combo`.

## What Changes

- Новый модуль `tests/test_config_edit.py`: полный цикл тестов канала записи — запись строки с аудит-комментарием (фиксированная дата через `now=`),append-семантика (повторный вызов дописывает вторую строку, дедупа нет — это текущий контракт), создание каталога, разбор `get_package_edit_lines` (отдельные/inline-комментарии, пустые строки, отсутствующий файл), `apply_user_patch` (путь `<patches>/<cat>/<pn>/<name>.diff`, заголовок).
- Все вызовы — только с явными `etc_dir`/`patches_dir` в tmp-корень; закрепляется, что за пределы переданного корня ничего не пишется.
- CLI-тесты связки `-a -p` и кластера `-ap` по семантике «pretend побеждает»: единственный прогон emerge содержит `--pretend`, merge-прогона нет, «Proceed?» не печатается и stdin не читается, rc — rc план-фазы (включая провал плана).
- Исходный код не меняется: если тесты вскроют дефект сверх зафиксированного контракта — он заводится отдельным изменением.

## Impact

- `tests/test_config_edit.py` (новый), `tests/test_cli.py`/`tests/test_cli_integration.py` — блоки тестов `-a -p`.
- Порядок: после `fix-ask-pretend-combo` (тесты закрепляют его семантику «pretend побеждает»; до него `-a -p` сегодня ведёт себя иначе).
- `src/emerge_ai/config_edit.py`, `src/emerge_ai/cli.py` — не трогаем.
- Пересечений с остальными изменениями нет (тестовые файлы другие, `test_ladder.py` не редактируем).
