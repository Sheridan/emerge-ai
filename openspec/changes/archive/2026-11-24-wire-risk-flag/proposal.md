# Proposal

## Why

Гейт в трёх местах обещает флаг `--i-understand-the-risks` (src/emerge_ai/gate.py:53,
61, 68 — в обоснованиях вердиктов, которые видит пользователь), но этот флаг
не входит в `OWN_FLAGS` (src/emerge_ai/flags.py:22-41): переданный, он уходит
emerge как неизвестный параметр, и emerge падает ещё до работы гейта
(REVIEW_NOTES M5). Единственный реальный флаг ответственности —
`--i-understand-what-i-am-doing-and-take-full-responsibility-for-consequences`
(flags.py:28-32) — подсказка гейта его не называет, и совет уводит пользователя
в тупик.

## What Changes

- `--i-understand-the-risks` становится собственным флагом emerge-ai:
  коротким псевдонимом флага полной ответственности, задаёт то же поле режима
  `responsibility`, действует во всех местах, где действует длинный флаг
  (матрица автономности, ветка `--noninteractive` в `-a`, оверлей/config-пути
  через режим).
- Обоснования вердиктов гейта (gate.py) начинают называть каноническое
  (полное) имя флага — подсказки ссылаются только на распознаваемые флаги.
- Справка по собственным флагам показывает псевдоним рядом с длинной формой.
- Длинный флаг и псевдоним идемпотентны по отдельности и вместе; оба не
  передаются emerge.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `cli-compat`: список собственных флагов пополняется псевдонимом; семантика
  разбора (точная позиция, полный матчинг, невдача emerge) не меняется.
- `agent-loop-consent`: матрица автономности принимает псевдоним как вход;
  сообщения обязаны ссылаться только на существующие флаги.

## Impact

- Код: `src/emerge_ai/flags.py` (запись псевдонима + строка справки),
  `src/emerge_ai/gate.py` (тексты обоснований :53, 61, 68; логика не меняется).
- Тесты: разбор псевдонима, идемпотентность пары флагов, e2e
  `--noninteractive --i-understand-the-risks` с stub emerge.
- Документация: README — псевдоним в списке собственных флагов.
- Смежные изменения: `wire-autonomy-gate` потребляет `mode.responsibility`
  как вход матрицы — псевдоним питает ровно это поле; тесты гейта с текстом
  подсказки обновляются здесь.
