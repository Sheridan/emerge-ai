# Spec Delta

## MODIFIED Requirements

### Requirement: Журнал только успешных решений
После успешной сборки emerge-ai SHALL записать в `/var/log/emerge-ai/journal.jsonl` запись: отпечаток сбоя, класс и контекст сбоя, применённое решение с перечнем выполненных действий, подтверждение успеха — повтор исходного сбоя emerge с кодом выхода 0. Неудачные решения записаны быть не могут. Перед разбором нового сбоя агент SHALL искать в журнале совпадающие отпечатки и использовать найденное решение как подсказку, а не как готовую команду.

#### Scenario: Повтор сбоя
- **WHEN** возникает сбой с отпечатком уже записанного успешного решения
- **THEN** агент предлагает найденное решение как вариант с пометкой об успешном прецеденте

#### Scenario: Решение не помогло
- **WHEN** применённое решение не привело к успешной сборке
- **THEN** в журнал ничего не записано

#### Scenario: Подтверждённый фикс записан
- **WHEN** применённое после согласия решение устранило сбой, и повтор emerge завершился кодом 0
- **THEN** в журнал добавлена одна запись с отпечатком сбоя, применённым решением и способом подтверждения успеха

## ADDED Requirements

### Requirement: Недоступный журнал не влияет на прогон
Отсутствие или нечитаемость файла журнала решений SHALL не мешать разбору
сбоя — агент работает без прецедентов; ошибка записи журнала SHALL
сопровождаться предупреждением пользователю и НЕ изменять код выхода уже
успешно завершённого прогона.

#### Scenario: Журнал ещё не создан
- **WHEN** первый в истории системы сбой разбирается при отсутствии файла журнала
- **THEN** агент разбирает сбой без прецедентов, ошибок пользователя нет

#### Scenario: Каталог журнала недоступен для записи
- **WHEN** фикс подтверждён успешным повтором emerge, но запись в журнал не удалась
- **THEN** пользователь видит предупреждение, прогон завершён кодом 0
