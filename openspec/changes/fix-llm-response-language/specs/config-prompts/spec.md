# Spec Delta

## MODIFIED Requirements

### Requirement: Язык ответов

Язык ответов LLM пользователю SHALL браться из `language`; `auto` SHALL определяться из
локали, настройка SHALL переопределять auto. Значение SHALL нормализоваться к полному
названию языка (`ru` → Russian; неизвестное — как есть). Директива языка SHALL входить в
каждый LLM-вызов с пользовательским выводом; в структурных JSON-ответах ключи и коды
действий остаются англоязычными, human-поля пишутся на целевом языке.

#### Scenario: Auto-язык

- **WHEN** `language: auto` и LANG=`ru_RU.UTF-8`
- **THEN** ответы агента на русском

#### Scenario: Явный код языка

- **WHEN** в конфиге `"language": "ru"`
- **THEN** во все пользовательские LLM-промпты (разбор инцидента, сводка дайджеста, news,
  анализ consent-меню, разбор config-файлов, changelog) входит директива с полным названием
  языка, вывод этих вызовов — на русском

#### Scenario: Структурные поля не двигаются

- **WHEN** разбор config-файлов или анализ consent-меню выполняется при `language: ru`
- **THEN** JSON-ключи и коды действий остались англоязычными, human-поля ответа — на
  русском
