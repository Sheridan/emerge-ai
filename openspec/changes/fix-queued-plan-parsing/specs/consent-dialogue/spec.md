# Spec Delta

## ADDED Requirements

### Requirement: Пункт merge различает недоступную и пустую очередь

Сценарий merge в consent-диалоге SHALL различать недоступную очередь и пустую: при
недоступном плане пункт показывает «queue unknown», при истинно пустой очереди —
«0 package(s)». Контракт точки восстановления для недоступной очереди обещает точку как
для очереди с защищаемыми пакетами (спека `system-rollback`).

#### Scenario: Недоступная очередь — не пустая
- **WHEN** план построить не удалось (резолвер недоступен) и consent-диалог показывает пункт merge
- **THEN** пункт читается как «queue unknown» (не «0 package(s)»), контракт точки восстановления обещает точку как для очереди с защищаемыми пакетами

#### Scenario: Истинно пустая очередь честна
- **WHEN** план построен и обновлять действительно нечего
- **THEN** пункт merge показывает «0 package(s)» — это правдивое состояние, а не следствие сбоя разбора
