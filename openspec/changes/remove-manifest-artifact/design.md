# Design

## Context

`manifest` в корне — 116-байтный stdout live-теста оверлея
(«manifest for /tmp/pytest-of-sheridan/pytest-133/… done»), закоммичен в
d886e4a. Появился, потому что live-тест того времени запускал эмулятор
`ebuild`/regen с cwd = корень репозитория и писал вывод в файл `manifest` в
cwd. Нынешние тесты изолированы в `tmp_path` (например,
tests/test_ladder.py:51 с фикстурой fake-ebuild пишет `Manifest` в
tmp-оверлей), так что артефакт — наследие, а не живой источник. В `.gitignore`
(6 правил: кэш, сборки, venv) шаблона для него нет.

## Goals / Non-Goals

- Goals: чистый checkout; защита от повторного случайного коммита; никаких
  изменений в коде и тестах.
- Non-Goals: переписывание истории (d886e4a остаётся как есть), поиск «того
  самого» старого теста (его уже нет в текущем виде), реформа изоляции
  остальных тестов.

## Decisions

- **D1. `git rm manifest`, а не удаление из рабочей копии без индекса.**
  Иначе файл останется в HEAD и вернётся у всех при следующем checkout.
  Альтернатива (`git rm --cached` + сохранение локальной копии) бессмысленна:
  содержимое — мусор.
- **D2. Шаблон `/manifest` (якорь в корне), а не `manifest`.**
  Глобальный `manifest` игнорировал бы одноимённые файлы в подкаталогах, где
  они могут быть легитимны; якорь покрывает ровно зафиксированный сценарий
  (cwd = корень при pytest). Регистр различается, `Manifest` оверлеев шаблон
  не задевает. Альтернатива — широкий шаблон вроде `*manifest*`: слишком
  заметно задевает легитимные файлы.
- **D3. Без спеков.** Изменение не меняет наблюдаемое поведение продукта —
  `skip_specs: true` в `.openspec.yaml`; артефакт репозитория не является
  требованием capability.

## Risks / Trade-offs

- [Старый локальный сценарий запуска снова создаст файл в корне] — `git status`
  его не покажет (игнор); риск — потерять полезный файл с таким именем, но
  легитимные `Manifest` пишутся в оверлеи, не в корень репозитория.
- [Переустановка глазами: «кто-то удалил нужный файл»] — в сообщении коммита
  указывается REVIEW_NOTES L7 и происхождение stdout-артефакта.
