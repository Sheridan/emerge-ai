# Design

## Context

`runner.py` — модуль-обёртка над emerge с двумя функциями: `run_emerge` (go + raw
stdio, «live-режим / ручные сценарии», `runner.py:14-16`) и `run_emerge_capturing`
(таймаут, `--nodeps --quiet`, захват и нормализация вывода, `:32`). Вторая используется
CLI для dry-run и live-прогона; первая — нет: все реальные прогоны идут через CLI,
который всегда получает вывод для парсинга отчёта/инцидентов. Имя осталось в импорте
`cli.py:23` как шум (M8).

## Goals / Non-Goals

**Goals:** в `runner.py` только достижимый код; ноль изменений поведения; удаление
приманки «запустить emerge без захвата вывода», обходящей разбор инцидентов.

**Non-Goals:** замена `run_emerge_capturing`; изменение флагов live-прогона
(`--nodeps`, `--quiet`); трогать константу `EMERGE` — она живая (`cli.py:266,326,384`).

## Decisions

**D1. Удалить, а не оставить «для будущего live-режима».** Сценарии live-прогона уже
реализованы через `run_emerge_capturing` (CLI сам решает флаги и показывает вывод
после захвата); go-обёртка без захвата никому не нужна сегодня, а когда понадобится —
её облик должен диктоваться конкретной спекой (нужен ли pty, стриминг, инциденты).
Рассмотренная альтернатива — оставить с пометкой deprecated: та же проблема, что с
`hooks.py` — мёртвый код, который читают как поддержку; отвергнута.

**D2. Удалять вместе с импортом, одним коммитом.** Если удалить только импорт, в
`runner.py` остаётся безымянная функция; если только функцию — сломается сборка
`cli.py`. Правка атомарна: `runner.py:14-16` + позиция `run_emerge` в `cli.py:23`.
Альтернатива — два коммита (импорт, затем функция): без фанатизма, выигрыша нет;
отвергнута.

## Risks

- [Внешний скрипт импортирует `runner.run_emerge`] → API не документирован (README/specs
  молчат), в changelog помечен BREAKING; восстановление — одна функция из истории гита.
- [Удаление заденет `run_emerge_capturing`] → функции не связаны (общая только константа
  `EMERGE`, которая остаётся); pytest `tests/test_runner.py` (тестирует только
  `run_emerge_capturing`) остаётся зелёным.
