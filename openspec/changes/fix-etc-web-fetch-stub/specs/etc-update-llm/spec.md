# Spec Delta

## MODIFIED Requirements

### Requirement: Решение LLM по каждому конфиг-файлу

Для каждого защищённого файла агент SHALL подготовить решение «оставить / выбросить /
смержить» с обоснованием и ссылкой на источник документации пакета (man, info, файлы
`/usr/share`, веб-поиск при включённом web-доступе). Веб-контекст SHALL загружаться
фактически — страница каталога пакетов по `<категория>/<пакет>` из пути файла либо поиск по
вики Gentoo; при недоступности сети веб-контекст SHALL становиться пустым с предупреждением
в stderr, а решение по файлу — готовиться как обычно.

#### Scenario: Новая опция в конфиге

- **WHEN** апстрим добавил в конфиг параметр, отсутствующий в локальном файле
- **THEN** агент предлагает смержить параметр с цитатой из документации

#### Scenario: Веб-доступ выключен

- **WHEN** в конфиге `agent.web_access` выключен
- **THEN** веб-запросы не выполняются вовсе, решение готовится по локальным источникам

#### Scenario: Веб-нет недоступен

- **WHEN** `agent.web_access` включён, но запрос к каталогу/wiki завершился ошибкой
  (сеть недоступна, страница не найдена, истёк тайм-аут)
- **THEN** в stderr выведено предупреждение, веб-контекст пуст, LLM-решение по файлу
  вынесено и показано пользователю как обычно

#### Scenario: Ошибка веб-фазы не подменяет ошибку LLM

- **WHEN** веб-загрузка завершилась любой ошибкой
- **THEN** сообщение об ошибке LLM (`etc LLM unavailable`) НЕ печатается, пакет не
  пропускается молча
