# Proposal

## Why

Сценарий «Новая опция в конфиге» (spec `etc-update-llm`) требует подтягивать веб-документацию
по имени пакета, но веб-фаза `_etc_flow` — нефункциональная заглушка, скопированная из теста:
`src/emerge_ai/cli.py:176-178` определяет замыкание `web(path)`, которое независимо от файла
тянет корневую страницу вики (`https://wiki.gentoo.org/`) и читает несуществующий ключ
`r["text"]` — `Sandbox.web_fetch` возвращает `{"url", "content", "truncated"}`
(`src/emerge_ai/sandbox.py:125-141`). `KeyError: 'text'` попадает под широкий
`except Exception` `cli.py:181-183`, который печатает `etc LLM unavailable: ...` и `continue` —
то есть **каждый** конфиг-файл молча пропускается, LLM-сверка не выполняется вообще никогда.
README (`README.md:154`) при этом утверждает, что документация «подтягивается из интернета».

## What Changes

- **BREAKING** — нет; поведение для пользователя только починяется.
- В `_etc_flow` вместо мёртвого замыкания с wiki-корнем появляется реальная загрузка
  веб-контекста:
  для путей вида `<...>/package.use*/<cat>/<pn>` используется страница
  `https://packages.gentoo.org/packages/<cat>/<pn>`, для остальных файлов — поиск
  `https://wiki.gentoo.org/index.php?search=<имя>&fulltext=1`; загрузка идёт через
  `Sandbox.web_fetch` (https-only, ограничение по времени/размеру, `sandbox.py:125`).
- Сетевые сбои (ошибка в ответе `web_fetch`, исключение, пустая страница) НЕ обрывают
  LLM-решение: список документации остаётся пустым, в stderr — предупреждение.
- Узкий `except` вокруг самого LLM-вызова остаётся, но больше не глотает ошибки веб-фазы:
  веб-фаза отвечает `[]`, а не исключение.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `etc-update-llm`: требование «Решение LLM по каждому конфиг-файлу» уточняется: веб-контекст
  загружается фактически при включённом `agent.web_access`, а недоступность сети — штатная
  ситуация с пустым контекстом, решение LLM выполняется всегда.

## Impact

- **Код**: `src/emerge_ai/cli.py` (`_etc_flow`: веб-фаза `:172-178`; `Sandbox()` там же
  создаётся на каждый файл — конструктор аргументов не требует, `sandbox.py:42-49`).
- **Тесты**: `tests/test_etcupdate.py` (`_etc_flow` уже импортирован там, `:8`) — success /
  failure / no-web-access пути с подменённым `Sandbox.web_fetch`; контракт
  `collect_docs(docs)` не меняется.
- **Docs**: README `:154` («документация подтягивается из интернета») становится правдой —
  сверить формулировку.
- **Смежные changes**: не пересекается с `etc-update-language` (та же функция, разные строки:
  промпт vs веб-фаза) — при одновременном применении применять первым этот change.
