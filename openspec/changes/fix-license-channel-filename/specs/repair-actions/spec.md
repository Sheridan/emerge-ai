# Spec Delta

## ADDED Requirements

### Requirement: Имя файла канала правки — то, что читает portage

Канал правки `package.*` SHALL называть файл правки так, как его называет
portage, а не по внутреннему имени вида: правка принятия лицензий пишется в
`package.license`, остальные виды — в файл вида. Файлы, которые portage не
читает, канал SHALL NOT создавать; каталог с читаемым именем трактуется как
каталожная раскладка. Одно и то же имя SHALL использоваться записью, отменой
строк прогона, обзором строк, текстом отмены и анонсом активности.

#### Scenario: Остальные виды пишут в файл вида

- **WHEN** исполняется правка вида `use`, `accept_keywords`, `mask`, `unmask`
  или `env` на хосте с файловой раскладкой
- **THEN** строка дописана в `package.use`, `package.accept_keywords`,
  `package.mask`, `package.unmask` или `package.env` соответственно — имена
  всех видов зафиксированы и сверены с перечнем читаемых portage имён

#### Scenario: Правка лицензий попадает в читаемый файл

- **WHEN** выбрана правка вида `accept_license` с строкой вида `www-servers/nginx *NEEDED-licence` и `/etc/portage` хранит файлы
- **THEN** строка с аудит-комментарием `# aimerge:` дописана в `package.license`, файл `package.accept_license` не создан и не изменён, перезапущенный emerge больше не сообщает о непринимаемой лицензии

#### Scenario: Каталог лицензий — файл категории

- **WHEN** `package.license` — каталог (каталожная раскладка) и выбрана правка лицензий для `dev-libs/foo`
- **THEN** строка дописана в `package.license/dev-libs`, файл `package.license` рядом с каталогом не создан, прочие файлы каталога не изменены

#### Scenario: Показанное и обещанное имя совпадают с записанным

- **WHEN** consent-формулировка правки лицензий показывает оператору строку «edit: …» и способ отмены, а затем правка исполняется
- **THEN** в формулировке, в анонсе активности и в фактическом пути записано `package.license` (или `package.license/<category>` на каталожной раскладке), а не имя вида

#### Scenario: Отмена и обзор работают с читаемым именем

- **WHEN** прогон дописал строку лицензий и его правки отменены, либо запрошен обзор строк правок лицензий
- **THEN** из `package.license` (включая файлы внутри, если это каталог) удалены только строки этого прогона с аудит-маркером, обзор показывает строки этого файла, ни один файл с именем, которое portage не читает, не создан

#### Scenario: У каждого вида есть читаемое имя файла

- **WHEN** в закрытый перечень видов правки добавлен новый вид
- **THEN** для него определено имя файла, которое читает portage, и тест сверяет весь перечень с множеством читаемых имён — вид, для которого имя не определено или ведёт в нечитаемый файл, не проходит проверку
