# Spec Delta

## Purpose

Делает enrich фазы плана по-настоящему LLM-обогощённым: к детерминированному ядру добавляется LLM-сводка плана, с явно нормированной деградацией до ядра без LLM.

## MODIFIED Requirements

### Requirement: Enrich для pretend/ask

При флагах `--pretend`/`--ask` emerge-ai SHALL напечатать штатный вывод emerge без изменений, после чего добавить обогащение: детерминированное ядро (genlop-оценка времени и tier-распределение) и LLM-сводку грядущих изменений по данным этого плана. Значения ядра SHALL печататься без изменений, LLM SHALL только интерпретировать план. При ненастроенном endpoint или сбое LLM-вызова сводка SHALL опускаться без прерывания план-фазы; финальный вопрос о продолжении SHALL задавать emerge-ai.

#### Scenario: Претенд с оценкой
- **WHEN** выполнено `emerge-ai -p sys-devel/gcc`
- **THEN** после списка emerge показаны оценка времени и дайджест изменений

#### Scenario: Ask с подтверждением
- **WHEN** выполнено `emerge-ai -a @world`
- **THEN** после вывода emerge с обогащением emerge-ai задал вопрос «Proceed?», при «y» установка продолжилась

#### Scenario: LLM-сводка поверх ядра
- **WHEN** endpoint LLM настроен и план собран
- **THEN** после строк ядра (tier-распределение, genlop-оценка) показана LLM-сводка, а значения ядра напечатаны без изменений

#### Scenario: Без endpoint — только ядро
- **WHEN** LLM endpoint не настроен и выполнено `emerge-ai -p app-editors/vim`
- **THEN** показано детерминированное ядро, LLM-блок отсутствует, предупреждений нет, вопрос о продолжении задан штатно

#### Scenario: Сбой LLM не рвёт план
- **WHEN** LLM-вызов сводки завершился ошибкой или таймаутом
- **THEN** показаны строки ядра, план-фаза продолжается, вопрос «Proceed?» задан
