# etc-update-llm Specification

## Purpose
Обработка защищённых конфигурационных файлов (config-protect) после сборки: LLM готовит решение по каждому файлу с опорой на документацию пакета, пользователь подтверждает, применение атомарно по одному пакету.

## Requirements

### Requirement: Обработка config-protect после сборки
При наличии опции «etc-update после сборки» включённой, emerge-ai SHALL после установки пакетов обнаружить все защищённые изменённые конфиги и передать их на разбор агенту; при выключенной опции — показать список изменений без действий.

#### Scenario: Опция выключена
- **WHEN** в конфиге `etc_update_after_build` выключен и появились config-protect файлы
- **THEN** emerge-ai показал список, изменений на диске нет

### Requirement: Решение LLM по каждому конфиг-файлу
Для каждого защищённого файла агент SHALL подготовить решение «оставить / выбросить / смержить» с обоснованием и ссылкой на источник документации пакета (man, info, файлы `/usr/share`, веб-поиск при включённом web-доступе).

#### Scenario: Новая опция в конфиге
- **WHEN** апстрим добавил в конфиг параметр, отсутствующий в локальном файле
- **THEN** агент предлагает смержить параметр с цитатой из документации

### Requirement: Подтверждение и атомарное применение по пакетам
Каждое решение SHALL подтверждаться пользователем до применения; применение SHALL быть атомарным — один пакет за раз, следующий пакет не обрабатывается, пока не завершён текущий.

#### Scenario: Отказ по одному пакету
- **WHEN** пользователь отклонил предложенное решение по пакету A из трёх
- **THEN** конфиги пакета A не изменены, обработка перешла к пакету B

#### Scenario: Откат решения на подтверждении
- **WHEN** пользователь изменил предложенное решение (например, вместо «смержить» выбрал «оставить»)
- **THEN** применено пользовательское решение, агент показал итоговый эффект

### Requirement: Язык обоснований
Обоснования решений по конфигам SHALL даваться на языке, настроенном для ответов агента.

#### Scenario: Русский язык
- **WHEN** в конфиге язык ответов `ru`
- **THEN** разбор конфигов выведен по-русски
