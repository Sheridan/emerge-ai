# cli-compat Specification

## Purpose
Определяет совместимость CLI aimerge со штатным emerge: сквозную передачу флагов и кодов выхода, собственные флаги режимов, перехват pretend/ask и привязку версии проекта к версии portage.

## Requirements

### Requirement: Passthrough флагов emerge
aimerge SHALL принимать полный набор опций emerge, передавать их штатному emerge без изменений и завершаться с кодом выхода запущенного emerge.

#### Scenario: Штатный запуск
- **WHEN** пользователь запускает `aimerge -uDN @world` и все сборки завершаются успешно
- **THEN** aimerge пробрасывает флаги emerge, печатает его вывод и завершается с кодом 0

#### Scenario: Ошибочный флаг
- **WHEN** пользователь передаёт флаг, неизвестный emerge
- **THEN** aimerge показывает штатную ошибку emerge и завершается с его кодом ошибки

### Requirement: Собственные флаги aimerge
aimerge SHALL распознавать собственные флаги `--noninteractive`, `--i-understand-what-i-am-doing-and-take-full-responsibility-for-consequences` (и его короткий псевдоним `--i-understand-the-risks`) и `--changelog` в любой позиции argv по полному точному совпадению (не по префиксу), повтор флага идемпотентен, и НЕ передавать их emerge; остальные аргументы передаются без изменений.

#### Scenario: Флаги не видны emerge
- **WHEN** пользователь запускает `aimerge --noninteractive -uDN @world`
- **THEN** emerge получает только `-uDN @world`, а aimerge включает неинтерактивный режим

#### Scenario: Полностью unattended
- **WHEN** переданы оба собственных флага
- **THEN** aimerge работает без вопросов и применяет решения агента на всех risk-tiers

#### Scenario: Точное совпадение вместо префикса
- **WHEN** пользователь передаёт аргумент `--noninteractiveX`
- **THEN** флаг не распознаётся как собственный и передаётся emerge без изменений

#### Scenario: Псевдоним флага ответственности
- **WHEN** запущено `aimerge --i-understand-the-risks -uDN @world`
- **THEN** emerge не получает этот аргумент, а aimerge работает в режиме полной ответственности

#### Scenario: Оба имени одного флага
- **WHEN** переданы и длинный флаг, и его псевдоним
- **THEN** режим полной ответственности включён однократно, поведение не отличается от одного флага

### Requirement: Мета-флаги версии и справки
aimerge SHALL распознавать `--version`/`-V` и `--help` только когда они являются первым аргументом argv: напечатать версию (aimerge и portage) или собственную справку и завершиться, не проверяя совместимость версий и не запуская emerge. В любой другой позиции эти строки SHALL передаваться emerge как обычные аргументы.

#### Scenario: Версия первым аргументом
- **WHEN** выполнено `aimerge --version`
- **THEN** напечатаны версии aimerge и portage, emerge не запущен, код выхода 0 (ненулевой — только если portage недоступен)

#### Scenario: Справка первым аргументом при несовместимом portage
- **WHEN** выполнено `aimerge --help` и версии portage/aimerge несовместимы
- **THEN** напечатана справка по собственным флагам aimerge, emerge не запущен, код выхода 0 (гейт совместимости не блокирует справку)

#### Scenario: Мета-флаг не на первой позиции
- **WHEN** выполнено `aimerge -p --help`
- **THEN** `--help` передан штатному emerge как аргумент, собственная справка aimerge не печатается

### Requirement: Возобновление через --resume
aimerge SHALL распознавать `--resume`: при наличии незавершённого run'а aimerge — продолжить его с сохранённым контекстом, не передавая `--resume` emerge; при отсутствии такого run'а `--resume` SHALL сохраняться в аргументах и передаваться штатному emerge (возобновление merge'а самого emerge), а запуск обрабатывается aimerge как обычный, без возобновления старого run'а.

#### Scenario: Возобновление run'а aimerge
- **WHEN** в runs-каталоге есть незавершённый run и выполнено `aimerge --resume ...`
- **THEN** run продолжается с сохранённого состояния и контекста инцидента, emerge не получает `--resume`

#### Scenario: Нет run'а aimerge — passthrough emerge
- **WHEN** незавершённых run'ов aimerge нет и выполнено `aimerge --resume`
- **THEN** emerge запущен с `--resume` как есть (штатная семантика emerge); старый run aimerge не возобновляется, вместо этого регистрируется обычный новый run

### Requirement: Привязка версии к portage
Версия aimerge SHALL равняться версии portage, на котором он выполняется. При запуске aimerge SHALL проверять, что `major.minor` версии portage равны `major.minor` версии aimerge; при несовпадении — вывести сообщение и завершиться с ненулевым кодом, не выполняя никаких действий emerge. Проверка SHALL не применяться к режимам, которые не запускают emerge и не используют python-API portage: `--version`/`-V`, `--help`, `--changelog`.

#### Scenario: Совместимые версии
- **WHEN** aimerge 3.0.82.2 запущен с portage 3.0.83
- **THEN** проверка проходит (3.0 == 3.0) и работа продолжается

#### Scenario: Несовместимые версии
- **WHEN** aimerge 3.0.82.2 запущен с portage 3.1.0
- **THEN** aimerge выводит сообщение о несовместимости python-API и выходит с ненулевым кодом

#### Scenario: Обходят проверку
- **WHEN** несовместимый portage и выполнено `aimerge --changelog`
- **THEN** дайджест новостей формируется без запуска emerge, код выхода 0

### Requirement: Поддержка только systemd
aimerge SHALL поддерживать только systemd-системы: рекомендации агента и системные действия SHALL использовать инструменты systemd (systemctl и т.п.) и SHALL не формировать сценарии для openrc. Перед любыми изменениями системы aimerge SHALL проверять init и при не-systemd SHALL отказывать без запуска emerge; режимы без изменений системы (план, дайджест новостей, мета-флаги) работают с предупреждением.

#### Scenario: Рекомендация по сервису
- **WHEN** решение требует перезапуска сервиса
- **THEN** агент предлагает действие через systemctl, без упоминания openrc-команд

#### Scenario: Host без systemd
- **WHEN** на OpenRC-хосте выполнено `aimerge app-editors/vim`
- **THEN** запуск завершён отказом с указанием, что поддерживаются только systemd-системы; emerge не запускался, система не изменена

#### Scenario: План на не-systemd host
- **WHEN** на OpenRC-хосте выполнено `aimerge -pNuDN @world`
- **THEN** показано предупреждение об отсутствии systemd, план сформирован, emerge запущен только в режиме pretend

#### Scenario: Мета-флаги не требуют systemd
- **WHEN** на OpenRC-хосте выполнено `aimerge --version`
- **THEN** версия напечатана, код выхода 0

### Requirement: Доминирование --pretend над --ask
При одновременном наличии `--pretend` (включая `-p` и кластеры вида `-ap`) и `--ask`/`--ask-forever` aimerge SHALL отработать только фазу плана: штатный pretend-вывод emerge с обогащением, без вопроса о продолжении, и SHALL NOT запускать merge-прогон; код выхода — код выхода pretend-прогона. Merge-прогон не запускается ни при каком ответе оператора.

#### Scenario: Связка -a -p не устанавливает
- **WHEN** выполнено `aimerge -a -p app-editors/vim` и оператор готов ответить «y» на любой вопрос
- **THEN** показан pretend-вывод с обогащением, вопрос «Proceed?» не задан, merge не запускался, код выхода — код pretend-прогона

#### Scenario: Кластер -ap
- **WHEN** выполнено `aimerge -ap app-editors/vim`
- **THEN** запуск ведёт себя как `-a -p`: только фаза плана, без вопроса и без merge

#### Scenario: -a без -p подтверждает и устанавливает
- **WHEN** выполнено `aimerge -a app-editors/vim` (без `--pretend`) и оператор ответил «y»
- **THEN** после обогащённого плана задан вопрос «Proceed?» и по «y» выполнен merge-прогон (прежнее поведение)
