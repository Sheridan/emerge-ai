# overlay-patching Specification

## Purpose
Лестница вмешательства при починке: наименее инвазивный уровень (конфиг/use/маски → user patches → ebuild в собственном оверлее aimerge) с аудит-следами и жизненным циклом оверлей-записей.

## Requirements

### Requirement: Лестница минимального вмешательства
Агент SHALL применять наименее инвазивный уровень, способный решить проблему: изменения `/etc/portage/package.*`; затем user patches `/etc/portage/patches/<cat>/<pn>` для патчей исходников; затем копия ebuild в оверлее aimerge. Собственный оверлей SHALL создаваться только когда успешная сборка возможна только после патча ebuild или исходников.

#### Scenario: Патч исходников
- **WHEN** сборка чинится правкой исходного кода
- **THEN** патч помещён в `/etc/portage/patches` без создания оверлей-ebuild

#### Scenario: Нужна правка ebuild
- **WHEN** без правки ebuild сборка невозможна
- **THEN** в оверлее aimerge создана копия ebuild с правкой

### Requirement: Аудит-комментарии правок конфигурации
Каждая правка `/etc/portage/package.*`, выполненная агентом, SHALL содержать комментарий `# aimerge: <дата> <journal-id> <причина>`.

#### Scenario: Правка package.use
- **WHEN** агент добавил USE-флаг по согласованному решению
- **THEN** рядом с записью стоит аудит-комментарий с journal-id

### Requirement: Реестр оверлея
Оверлей aimerge SHALL регистрироваться в `/etc/portage/repos.conf` и содержать для каждой записи метаданные: исходный ebuild, причина, ссылка на journal-id; записи SHALL быть видны приоритетнее основного дерева.

#### Scenario: Приоритет оверлея
- **WHEN** в оверлее лежит изменённый ebuild пакета
- **THEN** emerge использует версию из оверлея aimerge

### Requirement: Предложение удаления после апстрим-фикса
Когда portage обновился и исходный ebuild содержит фикс, aimerge SHALL обнаружить это и предложить удалить оверлей-запись; удаление без подтверждения пользователя SHALL NOT выполняться.

#### Scenario: Фикс пришёл в портедж
- **WHEN** после `--sync` дерево содержит исправленный ebuild
- **THEN** aimerge показывает предложение удалить дублирующую оверлей-запись
